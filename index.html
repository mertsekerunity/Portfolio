Multiplayer Stock Market Board Game (Solo Developer)

A 2.5D, character-based stock market board game for 3-6 players, built in Unity with server-authoritative multiplayer using Mirror. Each round has a bidding phase, character selection, and a main phase with buy/sell/ability moves, close-sell and tax resolution. using Mirror.

  • Closed draft / bidding system with player-specific character abilities
  • Open and close stock selling, bankruptcy/ceiling mechanics, lottery, tax and manipulation decks
  • Undo system with turn history and rollback of stock prices and money
  • Custom NetworkManager, NetPlayer, and Command → Server → TargetRpc flow

Tech: Unity(2022.3.55f1), C#, Mirror
